## [0.18.0] - 2026-10-30

### Bug Fixes
- Calendar event pop-ups no longer break page scrolling.
- You can now import calendar events specifically for "All Basic        Education" or "All College" groups.
- The calendar importer is now smarter at recognizing department abbreviations and names.
- Basic Education tracks are now correctly hidden from the calendar Program choices.
- The calendar import review screen now has better bulk editing and department controls.
- Image uploads for News and Announcements now work more reliably across different hosting servers.
- Uploading a homepage header image now correctly keeps the original photo shape.
- Graduate School administrators can now edit their Vision and Mission statements in the Content Editor.
- You can now leave the Graduate School header description completely blank.
- College Program photo slide edits now properly save as drafts instead of publishing immediately.
- College Program theme colors now show an instant preview before you publish them.
- You can now set different background images for desktop, tablet, and mobile views.
- The AI chatbot can now answer tuition questions directly from your uploaded PDF files.
- Fixed a visual glitch where College Program titles flashed their full name during page transitions.
- Archiving or restoring a Student Organization now works smoothly without causing database errors.

### New Features
- Clicking a date on the public calendar now opens a detailed pop-up with all the event information.
- The website footer now suggests different pages to visitors based on what they recently viewed.
- The footer features a cleaner layout with better spacing and a redesigned responsive campus map.
- You can now change text sizes and colors directly inside the Content Editor.
- You can now easily move Student Organizations from one page to another using the editor.
- The Calendar import tool has been completely redesigned into a full-screen, easy-to-use workspace.
- The calendar importer can now automatically read event locations directly from your uploaded Word documents.
- You can now safely archive or delete entire imported calendars at once.
- The calendar importer now compares your new upload with existing events to prevent accidental overwrites.
