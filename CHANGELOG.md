# Changelog

## [0.9.0-alpha] - 2026-09-30

### New Features
* Admin can now edit the college departments logo and head office.
* Admin can now edit the message from the president.
* Implemented the program curriculum pdf viewer in all programs.
* Admin can now pin news and announcements.
* Facebook posts are now displayed in the admin panel.
* Can now pin facebook posts.
* News and announcement page have an event sidebar.
* Added department category when creating an announcement.

### UI Improvements
* News and announcement page program categories is now a sidebar.
* Fixed icons so that you can customize the color through CSS.

### Bug Fixes
* Fixed time not reflecting in visitor side (index).
* Fixed upcoming events sidebar not showing upcoming dates when an event has multiple dates.
* Fixed bulletin board upcoming events color matching the category color.
* Fixed slideshow search not displaying all relevant results (e.g., searching for "Announcement" now properly retrieves all related posts/content).
* Fixed FB posts not being able to be categorized in the news and announcements page.
